# Forest Geo Tools

Python-скрипт для получения высот местности и предварительного расчёта уклона по географическим координатам.

## Функциональность

- Формирование сетки 3×3 вокруг заданной точки.
- Получение высот через Open Topo Data API (SRTM30m).
- Обработка данных с использованием NumPy.
- Расчёт угла уклона методом центральных разностей.

## Запуск

**Зависимости:** Python, NumPy, Requests.

```bash
pip install numpy requests
python terrain_slope.py
```

Координаты точки задаются непосредственно в коде в формате `(latitude, longitude)`.

## Метод расчёта

Изменения высоты по двум направлениям приближённо вычисляются по соседним точкам. Уклон определяется по величине градиента:

```python
slope = np.degrees(np.arctan(np.sqrt(dx**2 + dy**2)))
```

Где `dx` и `dy` — изменения высоты на единицу горизонтального расстояния по соответствующим осям.

## Ограничения

- Используется приближённый шаг сетки 30 м.
- Точки выборки не привязаны к исходной сетке пикселей SRTM.
- Результаты требуют проверки перед использованием в итоговом датасете.

**Источник высот:** [Open Topo Data](https://www.opentopodata.org/), SRTM30m.
